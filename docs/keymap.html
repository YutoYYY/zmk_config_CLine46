CLine46 キーマップ

Windows と Mac を同じ指の動きで使うための配列です。上の切替で、各レイヤーが Mac モードでどう変わるかを確認できます。

モード切替: /? 長押し ＋ W の位置 = Windows、A の位置 = Mac(電源を切っても保持)

そのまま使うキー Mac モードで中身が変わるキー このレイヤーを呼ぶために長押ししているキー(2つある場合は左右どちらか一方でOK) モード切替キー 下のレイヤー(Layer 0)のキーになる

LED の色の意味

LED はずっと点いているのではなく、電源を入れたとき・BT の枠を切り替えたとき・下のキーを押したときに一瞬光ります。

接続状態(右手) ― /?長押し＋I で表示

青: 選んでいる BT の枠が相手とつながっている
黄: 選んでいる枠が空。新しい相手とのペアリング待ち
赤: ペアリング済みだが相手が見つからない(相手の BT がオフ、または相手側で登録解除済み)

左手

青: 右手とつながっている
赤: 右手と切れている

電池残量(左右それぞれ) ― /?長押し＋, で表示

緑: 30% 以上
黄: 20〜30%
赤: 20% 未満。10% 未満になると定期的に赤く点滅
紫: 電池が検出できない

電源を入れたときは「電池残量 → 接続状態」の順に光ります。最初の黄色は電池、2回目の黄色は空の枠です。

Mac や Windows とつながらなくなったら
  1. /?長押しのまま L(BT 0)・K(BT 1)・J(BT 2)・U(BT 3)・O(BT 4)を順に押し、青に光る枠を探す
  2. 青がなければ、パソコン側の Bluetooth 設定で CLine46 を「登録解除」する
  3. キーボードで赤の枠を選び、/?長押し＋Esc(BT CLR)で空にする(黄になる)
  4. パソコンの Bluetooth 一覧に出る CLine46 に「接続」

BT CLR は選んでいる枠だけを消します。ほかのパソコンで使っている枠(青)では押さないでください。

パソコン側の前提設定

  • Windows: PowerToys Run の起動キーを Ctrl+Alt+Space に変更(🔍 で起動)
  • Mac: 修飾キーの入れ替えはしない(Control / Command は初期設定のまま)
  • Rectangle を「推奨」ショートカットで常駐させる
  • 音声入力のショートカットは「Control キーを2回押す」
  • クリップボード履歴は macOS 26 以降の Spotlight を使う
  • iPhone / iPad も修飾キーの入れ替えなしで Mac モードが使える

Mac モードで指の動きごと変わるもの

  • Ctrl の位置 + C / V / Z / S … は ⌘ + C / V / Z / S …
  • Ctrl + ← → は ⌥ + ← →(単語移動)、Ctrl + BkSp は単語削除
  • Alt を押したまま Tab 連打で ⌘Tab のアプリ切替
  • Home / End は行頭・行末、Ctrl + Home / End は文書の先頭・末尾
  • DYAStudio では Layer 7〜13 が Mac 用の差し替えレイヤー
